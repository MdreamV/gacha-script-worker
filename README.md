# GachaScriptWorker · 二游脚本总控

GachaScriptWorker 是一个 Windows 桌面自动化总控，用来按顺序执行多个二游的日常脚本。它会启动目标程序、模拟真实鼠标键盘操作、根据应用日志或游戏进程判断完成，并记录每次执行结果。

目前支持：

- 米游社签到（控制台脚本）
- 三月七 / 崩坏：星穹铁道
- 绝区零一条龙
- 明日方舟 MAA（模拟器由 MAA 自己管理）

> 本 README 面向日常使用。架构、日志判定、坐标校准和二次开发说明见 [AGENTS.md](AGENTS.md)。

## 功能

- 每天定时运行，默认 08:20。
- “立即运行全部”一键执行启用的脚本。
- 自由调整脚本顺序、启用/禁用、单独打开脚本。
- 运行前和每个脚本结束后自动清理目标程序，避免残留窗口影响下一次运行。
- 记录当前状态、耗时、完成情况和失败原因，保留最近 100 条运行历史。
- 支持系统托盘，关闭或最小化窗口不会中断定时任务。
- 单实例运行，避免重复调度。

## 运行环境

- Windows 10 / 11。
- Python 3.11 或更高版本（当前开发环境为 3.11.9）。
- 管理员权限：三月七和绝区零一条龙的启动器要求管理员权限，建议直接以管理员身份运行本程序。
- 目标脚本需要在本机已经能手动正常运行；本程序只负责调度和操作，不修复脚本自身的环境问题。

安装依赖：

```bat
pip install -r requirements.txt
```

## 快速开始

### 1. 启动

- 日常使用：双击 `启动总控.bat`（无控制台窗口）。
- 调试使用：双击 `调试启动.bat`（保留控制台，能看到异常信息）。

如果当前不是管理员权限，程序会提示是否以管理员身份重启。三月七和一条龙必须在管理员权限下才能正常启动。

首次启动会自动生成 `config.json`。

### 2. 配置并试跑

1. 在“脚本设置”中确认每个脚本的路径：
   - 米游社签到：选择脚本所在的**文件夹**（不是 exe）。
   - 三月七：选择 `March7th Launcher.exe`。
   - 绝区零一条龙：选择 `OneDragon-Launcher.exe`。
   - 明日方舟 MAA：选择 `MAA.exe`。
2. 勾选需要启用的脚本，用 ▲/▼ 调整执行顺序。
3. 点击“保存配置”。
4. 第一次测试建议只启用一个脚本，点击“立即运行全部”，确认流程无误后再启用全部。

> 自动化会真实接管鼠标和键盘。运行期间不要操作鼠标键盘，也不要玩游戏。

## 界面说明

### 脚本设置

- **启用**：是否参与“立即运行全部”和定时任务。
- **路径**：启动程序或脚本目录，可直接输入，也可点“浏览…”选择。
- **打开**：手动打开脚本本体。米游社签到会打开 PowerShell 并执行签到命令；GUI 脚本会直接启动对应程序。
- **▲ / ▼**：调整执行顺序，顺序即实际运行顺序。
- **保存配置**：把当前路径、启用状态、顺序和定时设置写入 `config.json`。

### 定时启动

- 勾选“启用每日定时启动”后，程序会在设定时间自动运行全部已启用脚本。
- 时间使用 24 小时制，例如 `08:20`。
- 界面会显示下一次预计运行时间。
- 如果到点时任务已经在运行，本次定时会跳过，不会重复启动。

### 运行控制

- **立即运行全部**：保存当前配置后立即执行。
- **停止任务**：在当前等待点停止；停止后仍会清理目标程序。
- **打开日志目录**：打开 `logs\`，其中包含总控日志和失败截图。
- **运行日志**：显示本次操作的实时日志。
- **执行状态**：显示每个脚本当前处于哪个阶段。
- **运行历史**：保留最近 100 条记录，包含开始/结束时间、耗时、状态和说明。

### 托盘

关闭或最小化主窗口会收起到右下角托盘。双击托盘图标重新打开；右键菜单可以打开配置、立即运行、停止任务或退出程序。

退出程序时如果有任务正在运行，会先确认并尝试停止任务。

## 四个脚本的说明

### 米游社签到

- 路径填写**脚本目录**，不是 exe。
- 总控会在该目录打开 PowerShell 并执行 `python main.py`。
- 需要该目录下的 Python 环境和依赖已经配置好，能手动运行。
- 成功结束后自动关闭 PowerShell 窗口；失败或超时会保留窗口，方便查看报错。
- 界面上的“打开”也会打开 PowerShell 并执行命令，但不会自动关闭。

### 三月七

- 需要管理员权限。
- 总控会自动把窗口调整到固定尺寸并点击“完整运行”。
- 启动时如果出现新版本提示，会自动点击“好的”跳过更新。
- 完成判定：游戏进程 `StarRail.exe` 启动并退出。
- 如果三月七修改了主题或按钮布局，自动点击可能失效，需要重新校准（见 [AGENTS.md](AGENTS.md)）。

### 绝区零一条龙

- 需要管理员权限。
- 总控会先点击左侧“一条龙”菜单，再发送默认的全局快捷键 `F9` 开始，并通过一条龙日志确认确实开始运行。
- 完成判定：游戏进程 `ZenlessZoneZero.exe` 启动并退出。
- 如果手动改过一条龙的开始快捷键，总控仍会按默认 F9 发送，需要同步调整配置代码。
- 运行中 F9 是暂停/继续，不要在总控运行期间手动按 F9。

### 明日方舟 MAA

- 总控**不启动、不关闭、不检查模拟器**，模拟器由 MAA 自己管理。
- MAA 如果开启了“启动后自动开启模拟器”，总控会等待模拟器启动完成后再点击左下角 `Link Start!`。
- 首次启动 MAA 的新手设置指引会由总控标记为已完成；如果 MAA 升级后重新出现指引，总控也会再次处理。
- 完成判定：`debug/gui.log` 出现当前这轮的 `任务已全部完成！`，**不以模拟器关闭为标志**。
- 如果 MAA 自身的“完成后动作”设置为退出模拟器，结束后模拟器会被 MAA 关闭，这是正常行为，不是总控执行的。
- 如果 MAA 报告连接失败，请先在 MAA 里手动确认模拟器和明日方舟能正常连接。

## 数据与文件

| 文件/目录 | 内容 | 是否上传 Git |
| --- | --- | --- |
| `config.json` | 本机配置：路径、启用状态、顺序、定时 | 否 |
| `state.json` | 最近 100 条运行历史 | 否 |
| `logs\worker_YYYYMMDD.log` | 总控运行日志 | 否 |
| `logs\failure_*.png` | 失败时的窗口截图 | 否 |
| `main.py` | 主界面、托盘、定时器 | 是 |
| `automation.py` | 窗口查找、点击、日志判定、进程清理 | 是 |
| `config.py` | 默认配置、路径解析、配置读写 | 是 |

`config.json`、`state.json`、`logs\`、`.idea\` 和 Python 缓存已加入 `.gitignore`，不会被误提交。

如果配置损坏，程序会把它重命名为 `config.json.bad` 并恢复默认配置。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示“脚本路径无效” | 检查路径是否存在；相对路径是相对本项目根目录，不是当前命令行目录 |
| “该程序要求管理员权限” | 退出后以管理员身份重新运行 `启动总控.bat` |
| 等待脚本窗口超时 | 先用“打开”手动启动，确认程序本身能打开、没有卡在登录/错误/更新窗口 |
| 三月七更新弹窗没有自动关闭 | 手动点一次“好的”，并查看失败截图；主题或布局变化后需要重新校准 |
| 一条龙没有开始 | 确认一条龙窗口停在“一条龙”页、快捷键仍为 F9、日志文件可读 |
| MAA 点击后没有开始 | 确认没有在 MAA 自动启动模拟器阶段误点“停止”，并查看 `debug/gui.log` |
| MAA 结束后模拟器被关闭 | 检查 MAA 自己的“完成后动作”，这是 MAA 的行为 |
| 点击位置偏移 | 不要手动调整目标窗口客户区大小；程序会按固定尺寸校准，尺寸变化后需要重新校准 |
| 修改代码后没有生效 | 旧进程可能仍在托盘运行，先从托盘退出再重新启动 |
| 提示程序已经在运行 | 查看右下角托盘，双击图标打开已有窗口 |

## 安全与注意事项

- **绝对不要读取、输出、复制、截图或提交**绝区零一条龙配置目录下的 `config\01\game_account.yml`。以 `config.json` 中 `zzz` 路径为基准，该文件位于一条龙启动器所在目录的 `config\01\game_account.yml`，保存了游戏账号的手机号和密码。排查问题不需要打开它。
- 失败截图和运行日志可能包含游戏 UID、账号信息或窗口内容，不要上传到公开仓库或外部服务。
- 自动化运行期间会真实移动鼠标、点击窗口并结束相关进程，请勿在运行期间使用电脑。
- 总控会关闭三月七、一条龙、MAA、星穹铁道和绝区零进程；**模拟器不在清理范围内**。
- 请自行确认使用自动化工具符合对应游戏和脚本的使用条款。
